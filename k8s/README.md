# Kubernetes Infrastructure (Legacy)

⚠️ **This code is no longer actively used** ⚠️

## Overview

This directory contains Terraform configurations from an old experiment with Kubernetes infrastructure in my homelab. The code represents a previous iteration of my homelab setup where I was exploring self-managed Kubernetes clusters on AWS.

## What's Included

This legacy K8s setup included:
- Kubernetes control plane and worker node provisioning
- IAM roles and policies for Kubernetes components
- Security groups and networking configuration
- Route53 DNS configuration for the cluster
- Bootstrap configurations for essential cluster components (ArgoCD, Calico, etc.)

## Why It's Preserved

This code is kept around for several reasons:

1. **Reference Material**: Useful for understanding past architectural decisions
2. **Learning Resource**: Examples of Terraform patterns for Kubernetes infrastructure
3. **Historical Context**: Documentation of homelab evolution and experiments
4. **Code Snippets**: Reusable patterns that might be applicable to future projects
